REROLL プライバシーポリシー

制定日: 2026-08-05 / 最終改定: 2026-08-10

REROLL（以下「本アプリ」）は、Steam で配信されているローグライク/ローグライト作品を発掘するための iOS アプリです。本ポリシーは、本アプリが取り扱う情報について説明します。

1. 本アプリが収集する情報

本アプリは、ユーザーの個人情報を収集しません。

  • アカウント登録はありません。
  • お気に入り、閲覧履歴、設定は、すべてお使いの端末内にのみ保存されます。開発者のサーバーに送信されることはありません（開発者はサーバーを保有していません）。
  • 広告 SDK は使用していません。利用状況の計測は第3項のとおり匿名で行います。

2. 外部サービスとの通信

本アプリは、コンテンツの表示のために端末から以下の外部サービスへ直接通信します。通信に伴い、IP アドレス等の通信情報が各サービスの運営者に送信されます。

  • Steam（Valve Corporation）: ゲーム情報・画像・動画・レビュー・プレイヤー数の取得のため。Valve のプライバシーポリシー
  • GitHub Pages（GitHub, Inc.）: 本アプリが表示するゲームリストデータの取得のため。GitHub プライバシーステートメント
  • TelemetryDeck（TelemetryDeck GmbH）: 第3項の匿名計測イベントの送信先。TelemetryDeck のプライバシーポリシー

これらの通信で、ユーザーを識別する情報（氏名・メールアドレス等）が送信されることはありません。

3. 利用状況の匿名計測

本アプリは、機能改善のために利用状況の匿名計測を行います（TelemetryDeck を利用）。

  • 送信されるのは「アプリを起動した」「カードをお気に入りに登録した」といった操作イベントのみです。
  • 氏名・メールアドレス・広告 ID・端末 ID など、個人を特定できる情報は含まれません。
  • 識別子は初回起動時にアプリ内で生成されるランダムな ID の不可逆ハッシュで、個人と紐付けることはできず、アプリを削除すると消滅します。

4. 本ウェブサイト（rerolldeck.com）について

本ポリシーを掲載しているウェブサイトでは、アクセス状況の把握のために Cookie を使わない匿名のアクセス解析（GoatCounter）を利用します。

  • Cookie は使用しません。同意バナーも表示しません。
  • IP アドレスは保存されません（同一の訪問かどうかの判定に、その日限りの不可逆ハッシュを用います）。
  • 記録されるのは、閲覧されたページ・参照元・おおまかな国とブラウザ種別のみです。

5. 本ポリシーの改定

機能追加（利用状況の計測等）により取り扱う情報が変わる場合は、本ポリシーを改定し、このページで告知します。
